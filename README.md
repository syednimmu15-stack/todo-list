# Student Task Manager

A beginner-friendly To-Do List project built with HTML, CSS, and JavaScript. Tasks are stored in your browser with `localStorage`.

## Features
- Add new tasks
- Mark tasks as completed
- Filter by All, Active, and Completed
- Delete individual tasks
- Clear all completed tasks
- Save tasks in the current browser
- Responsive layout for mobile and desktop

## Run locally
1. Download and unzip the project.
2. Open `index.html` in a web browser.
3. Add a task to get started.

No installation or build tools are required.

## Publish with GitHub Pages
1. Create a GitHub repository named `student-task-manager`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages** in your repository.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Project structure
```text
student-task-manager/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Customization
Edit `style.css` to change the colors and layout, or edit `index.html` to change the page text.
